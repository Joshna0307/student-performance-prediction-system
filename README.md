# EduPredict AI

**Intelligent Student Performance Prediction and Academic Risk Detection System Using Deep Learning**

EduPredict AI analyzes academic and behavioral factors to estimate final exam marks, identify weak subjects, and flag students who may benefit from support. Predictions are advisory—not guarantees or diagnoses.

## Stack
- React + Vite + Tailwind-ready UI + Chart.js
- Python Flask REST API
- TensorFlow/Keras ANN
- Pandas, NumPy, Scikit-learn, SHAP (optional)
- SQLite starter database

## Features
- Student academic input form (10 factors)
- ANN model training and inference
- What-if simulator
- Feature importance/explanation
- Weak-subject analysis
- Early academic risk indicators
- Student/faculty/admin dashboard foundation
- CSV upload and prediction history foundations

## Run locally
### Backend
```bash
cd backend
python -m venv .venv
# Windows: .venv\\Scripts\\activate | macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python train.py
python app.py
```
### Frontend
```bash
cd frontend
npm install
npm run dev
```
Frontend defaults to API URL `http://localhost:5000`. Set `VITE_API_BASE_URL` if needed.

## Dataset/model caveat
Training data generated by `train.py` is synthetic, for demonstration and software testing. Metrics from synthetic data do not establish real-world validity. Replace it with an ethically sourced, institution-approved dataset and evaluate calibration, bias, generalization and privacy before deployment.
